# Page Inventory

Source of truth: `Front-End/src/App.tsx` route definitions and the page components those routes render.

## Guard Semantics

- Unguarded routes in `App.tsx` render their page component directly, with no `ProtectedRoute` or `PublicOnlyRoute` wrapper (`Front-End/src/App.tsx:44`, `Front-End/src/App.tsx:45`, `Front-End/src/App.tsx:46`, `Front-End/src/App.tsx:47`, `Front-End/src/App.tsx:48`, `Front-End/src/App.tsx:231`, `Front-End/src/App.tsx:232`).
- `PublicOnlyRoute` is used for auth pages; when `auth.token` exists it redirects by `getRedirectPathForRole(auth.user?.role)` instead of rendering children (`Front-End/src/components/ProtectedRoute.tsx:69`, `Front-End/src/components/ProtectedRoute.tsx:80`, `Front-End/src/components/ProtectedRoute.tsx:81`).
- `ProtectedRoute` redirects missing-token users to `/login` (`Front-End/src/components/ProtectedRoute.tsx:23`, `Front-End/src/components/ProtectedRoute.tsx:24`).
- `ProtectedRoute requireAdmin={true}` permits `Admin` and `SuperVisor`, and renders "Access Denied" for other roles (`Front-End/src/components/ProtectedRoute.tsx:28`, `Front-End/src/components/ProtectedRoute.tsx:29`, `Front-End/src/components/ProtectedRoute.tsx:33`).
- `ProtectedRoute requireStudent={true}` blocks only role `User`; any authenticated role other than exactly `User` reaches the child page (`Front-End/src/components/ProtectedRoute.tsx:45`, `Front-End/src/components/ProtectedRoute.tsx:46`, `Front-End/src/components/ProtectedRoute.tsx:66`).
- Pages using `Layout` inherit role-based navigation: anonymous users see Login/Register, `Student` and admin roles see Dashboard, `User` sees Course/Verify Certificate, and admin roles see Admin (`Front-End/src/components/Layout.tsx:45`, `Front-End/src/components/Layout.tsx:57`, `Front-End/src/components/Layout.tsx:65`, `Front-End/src/components/Layout.tsx:79`).
